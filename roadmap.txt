PENUMBRA-WRAPPER ROADMAP
========================
Goal: Own GUI wrapper that is built on top of a REAL GitHub fork of the
original shomykohai/penumbra (the main repo), with antumbra nightly
builds hosted on my own account.

Repo layout:
  - coolishsec0175/penumbra-wrapper  -> my own GUI app (wrapper)
  - coolishsec0175/penumbra          -> REAL fork of shomykohai/penumbra (core/antumbra)

Phase 1 - Core fork (penumbra)
  1. Create coolishsec0175/penumbra as a real GitHub fork of
     shomykohai/penumbra (the MAIN repo, not ardiandideyashidiq's fork).
  2. Enable GitHub Actions on the fork.
  3. Add a Windows-only nightly CI (.github/workflows/release.yml):
       - build antumbra: cargo build --release -p antumbra --features penumbra/serial
       - upload antumbra-x86_64-windows.exe to the "nightly" release
         with a sha256 digest (GitHub auto-adds the digest field).
  4. Push and verify the nightly release exists with the binary + digest.

Phase 2 - Sync wrapper to the new core
  5. Update the wrapper's vendored penumbra-core/ to match the new fork
     (based on shomykohai main) so the GUI talks to the same core.
  6. Point antumbra_update.rs + diagnostics.rs to:
       https://api.github.com/repos/coolishsec0175/penumbra

Phase 3 - End-to-end test
  7. Rebuild the wrapper, install it.
  8. Click "Update Antumbra" and confirm it downloads/installs from my
     own repo (not ardiandideyashidiq's).

Phase 4 - Polish / improvements
  9. Rebrand: Cargo.toml authors, productName, app icon, version
     (wrapper 0.1.0 vs core 1.1.0 mismatch).
 10. Wrapper self-update: set includeUpdaterJson true.
 11. Release profile: opt-level="z", lto, codegen-units=1, panic="abort",
     strip="symbols" for smaller/faster binaries.
 12. Fix npm run lint (ignore vendored penumbra-core/docs).
 13. Add "app" bundle target so the raw penumbra-wrapper.exe is also
     uploaded to releases.
 14. Write a README.md with credits: original core by shomykohai/penumbra,
     wrapper base by ardiandideyashidiq/penumbra-wrapper, plus any
     contributors.

Done = fully self-hosted:
  - Wrapper GUI from coolishsec0175/penumbra-wrapper
  - Antumbra binary from coolishsec0175/penumbra (fork of shomykohai main)
